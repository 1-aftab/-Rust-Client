## 2. What Rust Client is

Rust Client is a free, open-source Android launcher with two game editions:

- **Java Edition** runs Minecraft: Java Edition with a Java runtime on your device.
- **Rust Edition** runs a native game engine that needs no Java runtime while you play.

Rust Client is unofficial. It is not affiliated with, endorsed by, or sponsored by Mojang Studios or Microsoft. It does not give you a licence to Minecraft or a game account. Rust Client ships none of Minecraft's files; the files a game needs are downloaded to your device from their publishers' servers when you ask for them.
